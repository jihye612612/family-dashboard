# 우리 가족 기록장 🏡

엄마 · 도완 · 도은을 위한 가족 대시보드. 휴대폰과 태블릿에서 같은 주소를 열면 기록이 함께 보여요.

**라이브 주소:** https://jihye612612.github.io/family-dashboard/
(휴대폰 브라우저에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.)

## 무엇이 있나요

- **가족 카드** — 엄마(치이카와 스타일) / 도완(하치와레 스타일) / 도은(우사기 스타일) 먼작귀 캐릭터, 이 기기 사용자 선택(기기마다 기억), 칭찬 별(+1)
- **오늘의 가족 미션** — 🎲 다시 고르기, 우리 가족 미션 직접 추가
- **미션 도장판** — "다 같이 했어요!"를 누르면 도장이 찍히고 🙌 하이파이브 축하가 떠요
- **가족 채팅방** — 메시지, 빠른 스티커, ❤️ 반응, 📷 사진 보내기, 🎙️ 음성메시지
- **타이머** — 10/20/30분 · 직접 입력, 시작/멈춤/리셋, 종료 시 소리 + 전체 화면 알람
- **태블릿 끄는 알람** — 정한 시각에 소리와 전체 화면 알람 (이 기기에서만)
- **날씨** — 대구 기본, 설정에서 다른 도시로 변경 (Open-Meteo)

## 한눈에 보기

엄마·도완·도은은 각자 **먼작귀(ちいかわ)** 느낌의 얼굴로 그렸어요.

- **엄마 = 치이카와** — 포동포동한 하얀 둥근 얼굴에 작고 동그란 귀, 연한 핑크 볼, `ω` 입
- **도완 = 하치와레** — 하얀 얼굴에 하늘색 뾰족 고양이 귀와 이마 양갈래 가르마 무늬
- **도은 = 우사기** — 연노랑 둥근 얼굴에 위로 길쭉한 토끼 귀(안쪽 연핑크), 장난스러운 표정

그림은 이미지 파일이 아니라 `app.js`의 `avatarSVG`가 그리는 SVG라서, 카드·선택 버튼·채팅 말풍선 어디에 있어도 선명하게 보이고 로딩이 없어요.

## 사진 보내기 📷

채팅방 입력칸 옆 **📷** 버튼을 누르면 휴대폰에 있는 사진을 골라 보낼 수 있어요.

- 고른 사진은 보내기 전에 이 기기에서 **긴 쪽 960px · JPEG 0.78**로 줄여서, 휴대폰 사진도 금방 올라갑니다.
- 입력칸에 글을 먼저 써 두고 사진을 고르면 그 글이 **사진 설명**으로 함께 붙어요. (글 없이 사진만 보내도 됩니다.)
- 사진을 올리는 동안 📷 버튼이 ⏳로 바뀌고 "사진 올리는 중…" 이 보여요.
- 채팅 말풍선 안의 사진을 누르면 **크게 보기**가 열려요. (닫기 버튼 또는 바깥을 누르면 닫혀요.)

**3시간만 보관돼요.** 사진은 ntfy.sh의 파일 보관소에 올라가고 거기 보관 기간이 3시간이라, 그 뒤에 열면 말풍선에 "만료된 사진이에요 (3시간 보관)" 이라고 나옵니다. 그때도 글과 "보냈던 사실"은 그대로 남아요. 오래 두고 보고 싶은 사진은 휴대폰 갤러리에도 남겨 주세요.

사진은 채팅 주제가 아니라 사진 전용 주제(`방이름-files`)로 올라가서, 채팅 기록에는 사진 주소만 들어갑니다.

## 음성메시지 보내기 🎙️

채팅방 입력칸 옆 **🎙️** 버튼을 누르면 그 자리에서 말을 녹음해 바로 보낼 수 있어요.

- **한 번 누르면 녹음 시작** — 버튼이 `⏹️ 0:03` 처럼 바뀌며 지난 시간이 보여요.
- **다시 누르면 녹음 끝** — 바로 올라가고 상대 말풍선에 `🎙️ 음성메시지 (0:08)` 와 재생 플레이어가 나타나요.
- 한 번에 **최대 60초**까지 녹음되고, 60초가 되면 저절로 끝나서 보내요. 올리는 동안 버튼은 ⏳ 로 바뀝니다.
- 처음 누를 때 브라우저가 **마이크 사용을 물어보면 허용**해 주세요. (허용하지 않으면 "마이크 사용을 허용해 주세요" 안내가 나옵니다.)
- 휴대폰마다 받아 주는 녹음 형식이 달라서 `audio/mp4`(아이폰·사파리) → `audio/webm`(안드로이드·크롬) 순으로 기기에 맞는 형식을 저절로 고릅니다.

**사진과 똑같이 3시간만 보관돼요.** 음성도 ntfy.sh의 같은 파일 보관소(`방이름-files`)에 올라가고 보관 기간이 3시간이라, 그 뒤에 열면 말풍선에 "⏳ 3시간이 지나 만료된 음성메시지예요" 가 나옵니다. 그때도 누가 언제 보냈는지는 그대로 남아요.

## 시작하기: 우리 가족 비밀번호

화면을 처음 열면 **🔒 우리 가족 비밀번호** 잠금 화면이 보여요.

1. 가족끼리 쓸 비밀번호를 정해요. (4글자 이상이면 무엇이든 좋아요. 예: `우리집`, `dowanlove`, `2024가족`)
2. 첫 기기에서 그 비밀번호를 넣고 **들어가기**를 눌러요.
3. 다른 가족 기기도 **똑같은 비밀번호**를 한 번씩 넣어 주세요. 같은 비밀번호 = 같은 방이라서 기록이 함께 보여요.

- 한 번 넣은 기기는 기억하므로, 다음부터는 잠금 화면 없이 바로 열려요.
- 비밀번호를 바꾸고 싶으면 설정(⚙️) → **비밀번호 다시 입력 / 기기 잠금** 을 누르고 새 비밀번호를 넣으면 돼요. 이때는 가족 모두 **같은 새 비밀번호**로 다시 들어와야 기록이 이어져요.
- 비밀번호를 잊어버리면 그 기기에서는 설정(⚙️) → "이 기기 기록 지우기" 후 새 비밀번호로 다시 시작하면 돼요. (각 기기에 남아 있던 기록은 지워져요.)

## 여러 기기 동기화

같은 비밀번호를 넣은 기기끼리 자동으로 같은 방에 연결됩니다.

- 방 이름은 저장소에 적혀 있지 않고, 기기 안에서 비밀번호로 계산합니다. (`'pickle-family-v2:' + 비밀번호` → SHA-256 → `pkf-` + 앞 28자)
- 비밀번호 원문은 어디에도 저장하거나 보내지 않아요. 이 기기에는 계산된 방 이름만 남습니다.
- 실시간 수신: ntfy 공용 채널의 SSE 스트림
- 실시간 연결과 별개로 **6초마다 안전망 폴링**이 함께 돌아서, 휴대폰에서 SSE가 조용히 멈춰도 10초 안에 새 채팅을 받아옵니다. 화면을 다시 켜거나 인터넷이 돌아오면 조건 없이 바로 한 번 받아오고 실시간 연결도 새로 맺어요.
- 채팅방 제목 옆 **🔄** 또는 설정(⚙️)의 **🔄 지금 동기화**를 누르면 바로 한 번 받아오고 가족에게 "지금 상태 알려줘"를 보냅니다.
- 두 기기가 같은 방에 있는지 **방 코드**(`#xxxx`, 방 이름 끝 4자리)로 확인할 수 있어요. 채팅방 하단 상태와 설정에 보입니다. 기기끼리 코드가 다르면 서로 다른 비밀번호로 들어온 것이니 같은 비밀번호로 다시 들어가면 돼요.
- 오프라인이어도 이 기기(localStorage)에 먼저 저장되고, 연결되면 다시 올라갑니다
- 채팅·별·도장·미션은 합집합으로 합쳐져서 서로 덮어쓰지 않아요

동기화 채널에는 가족 이름과 대화 내용이 오가므로, **가족만 아는 비밀번호**를 쓰는 것이 곧 잠금입니다. `1234`처럼 흔한 숫자만 쓰면 다른 사람이 추측할 수 있으니, 가족만 아는 단어를 섞어 조금 길게 정해 주세요.

### 알아 두면 좋은 점

- 기록은 각 기기의 localStorage에 먼저 저장되고, 클라우드 채널(ntfy.sh)은 기기 사이를 이어 줍니다.
  채널의 메시지 보관 기간은 12시간이라, 오래 쉬었다 켜도 각 기기에 남은 기록으로 이어집니다.
- 켤 때는 기록을 올리지 않고 "지금 상태 알려줘"만 보냅니다. 다른 기기가 있으면 그 기기가 최신 기록을 돌려줍니다.
- 하루 메시지 한도(250개)와 분당 요청 한도가 있어, 평소 가족 사용에는 넉넉하지만 아주 많은 대화가 오가면 잠시 동기화가 늦어질 수 있습니다.
- 소리(타이머·알람)는 브라우저 정책상 **한 번 화면을 눌러 준 뒤**부터 울립니다. 알람은 화면을 켜 둔 상태에서 동작해요.
- 태블릿 끄는 알람은 그 기기에서만 울립니다.

## 구성

- `index.html` — 화면 구조 (가족 비밀번호 잠금 화면 포함)
- `styles.css` — 파스텔 테마, 반응형
- `app.js` — 잠금·방 이름 계산, 상태·동기화·채팅(사진·음성 포함)·타이머·알람 (빌드 없음, 순수 HTML/CSS/JS)

GitHub Pages(main 브랜치 루트)로 배포됩니다.
